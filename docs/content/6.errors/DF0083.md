description: 'MCP prompt "{name}" is missing the required argument(s): {missing}.'

## Message

> MCP prompt "`{name}`" is missing the required argument(s): `{missing}`.

## Cause

An MCP client sent `prompts/get` for a prompt that marks one or more of its `arguments` as `required: true`, but left out a value for them or sent an empty string. The MCP server answers with an invalid-params error (`-32602`) that carries this message, and the code, fix and docs link in its `data`. The prompt's `get` function does not run.

## Example

```ts
initDevframe(myDevframe, {
  mcp: {
    prompts: [{
      name: 'review-file',
      arguments: [{ name: 'file', required: true }],
      get: ({ file }) => ({ messages: [{ role: 'user', content: { type: 'text', text: `Review ${file}.` } }] }),
    }],
  },
})
// An MCP client calls: prompts/get { name: 'review-file', arguments: {} } → DF0083
```

## Fix

Call `prompts/list` to see the arguments of the prompt, then send a non-empty value for each required one.

## Source

- [`packages/agentic/src/mcp/build-server.ts`](https://github.com/devframes/devframe/blob/main/packages/agentic/src/mcp/build-server.ts): the `prompts/get` handler in `registerPromptHandlers()` throws this when a required argument is missing or empty.
