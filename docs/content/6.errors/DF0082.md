---
title: 'DF0082: Unknown MCP Prompt'
description: 'Unknown MCP prompt "{name}".'
---

## Message

> Unknown MCP prompt "`{name}`".

## Cause

An MCP client sent `prompts/get` with a `name` that is not in the `prompts` list of the MCP route options (or of `createMcpServer` / `createMcpFetchHandler`). The MCP server answers with an invalid-params error (`-32602`) that carries this message, and the code, fix and docs link in its `data`.

## Example

```ts
initDevframe(myDevframe, {
  mcp: { prompts: [{ name: 'review-file', get: () => ({ messages: [] }) }] },
})
// An MCP client calls: prompts/get { name: 'reveiw-file' } → DF0082
```

## Fix

Call `prompts/list` to get the names of the available prompts, then retry with one of them.

## Source

- [`packages/agentic/src/mcp/build-server.ts`](https://github.com/devframes/devframe/blob/main/packages/agentic/src/mcp/build-server.ts): the `prompts/get` handler in `registerPromptHandlers()` throws this when no prompt has the requested name.
